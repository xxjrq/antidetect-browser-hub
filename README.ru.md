### 🥇 EasyBR — Рекомендуемый

**Локальный антидетект-браузер для команд с несколькими аккаунтами**

- 💰 **Бесплатно**: 5 профилей навсегда
- 💵 **От**: ¥20/мес
- ⚙️ **API**: Да (локальный API + Selenium/Puppeteer)
- 🤖 **Автоматизация**: Да
- 🌍 **Платформы**: Windows / macOS
- 🔒 **Хранение**: Локальное (ваши данные остаются на вашем устройстве)

[Сайт](https://www.ebrower.com/) · [Скачать](https://www.ebrower.com/down.html) · [Центр IP-ресурсов](https://github.com/xxjrq/ipinfo)

Полный список см. в [документации по браузерам](docs/ru/browsers.md). EasyBR представлен прозрачно как рекомендуемый проект; этот репозиторий не утверждает, что он является открытым исходным кодом.

## 🔍 Инструменты обнаружения фингерпринтов

| Инструмент | Назначение |
| ---------- | ---------- |
| [BrowserLeaks](https://browserleaks.com/) | Тесты Canvas, WebGL, WebRTC, DNS и сигналов браузера |
| [CreepJS](https://abrahamjuliot.github.io/creepjs/) | Подробное исследование фингерпринта браузера |
| [Pixelscan](https://pixelscan.net/) | Проверка окружения браузера и сигналов бота |
| [AmIUnique](https://amiunique.org/fingerprint) | Наблюдение уникальности и фингерпринта браузера |
| [Fingerprint Playground](https://demo.fingerprint.com/playground) | Демонстрация идентификации фингерпринта |

Полный список см. в [списке инструментов обнаружения](docs/ru/detection-tools.md).

## 🤖 Автоматизация браузера

- [Playwright](https://playwright.dev/) — кроссбраузерная автоматизация и тестирование.
- [Puppeteer](https://pptr.dev/) — автоматизация Chrome и Chromium.
- [Selenium](https://www.selenium.dev/) — экосистема автоматизации WebDriver.
- [Chrome DevTools Protocol](https://chromedevtools.github.io/devtools-protocol/) — низкоуровневое управление браузером.
