# 网络、代理与连接指纹资源

## 连接检测

- [BrowserLeaks WebRTC](https://browserleaks.com/webrtc) — WebRTC 候选地址检查。
- [BrowserLeaks DNS](https://browserleaks.com/dns) — DNS 解析路径检查。
- [DNS Leak Test](https://dnsleaktest.com/) — DNS 泄漏测试。
- [TLS Peet](https://tls.peet.ws/api/all) — TLS、HTTP/2 和请求特征。
- [ProxyDetect](https://proxydetect.live/) — 代理/VPN 风险信号参考。
- [IPQualityScore](https://www.ipqualityscore.com/) — IP 信誉和风险信号。
- [FingerBank](https://fingerbank.org/) — 网络设备指纹数据库与 API。

## 代理 IP 服务商资源

代理服务商不在本仓库重复维护，统一使用 EasyBR 的开源 IP 资源库：

- [GitHub：xxjrq/ipinfo](https://github.com/xxjrq/ipinfo)
- [在线 IP 资源中心](https://xxjrq.github.io/ipinfo/)

该项目已整理住宅代理、静态住宅、数据中心代理、移动代理和国内外服务商，并提供 JSON/CSV 数据。
