## 🔍 Ferramentas de Detecção de Fingerprint

| Ferramenta | Propósito |
| ---------- | --------- |
| [BrowserLeaks](https://browserleaks.com/) | Testes de Canvas, WebGL, WebRTC, DNS e sinais do navegador |
| [CreepJS](https://abrahamjuliot.github.io/creepjs/) | Pesquisa detalhada de fingerprint do navegador |
| [Pixelscan](https://pixelscan.net/) | Verificação de ambiente do navegador e sinais de bot |
| [AmIUnique](https://amiunique.org/fingerprint) | Observação de unicidade e fingerprint do navegador |
| [Fingerprint Playground](https://demo.fingerprint.com/playground) | Demonstração de identificação de fingerprint |

Consulte a lista completa de [ferramentas de detecção](docs/pt-BR/detection-tools.md).
