# Automation Libraries and Runtimes

Choose an automation stack based on browser coverage, debugging support, accessibility, test stability and the rules of the target service.

## Browser automation

- [Playwright](https://playwright.dev/) — cross-browser end-to-end automation.
- [Puppeteer](https://pptr.dev/) — Chrome and Chromium automation.
- [Selenium](https://www.selenium.dev/) — established WebDriver ecosystem.
- [WebdriverIO](https://webdriver.io/) — JavaScript automation framework.
- [Cypress](https://www.cypress.io/) — web application testing.
- [Chrome DevTools Protocol](https://chromedevtools.github.io/devtools-protocol/) — low-level browser control.
- [Nodriver](https://github.com/ultrafunkamsterdam/nodriver) — Python browser control without the traditional driver model.
- [Selenium Driverless](https://github.com/kaliiiiiiiiii/Selenium-Driverless) — driverless Selenium experiments.

## Interaction helpers

- [Ghost Cursor](https://github.com/Xetera/ghost-cursor) — mouse path generation.
- [HumanCursor](https://github.com/riflos/HumanCursor) — human-like cursor utilities.
- [nut.js](https://nutjs.dev/) — desktop input automation.
- [Bezier.js](https://github.com/Pomax/bezierjs) — Bézier curve utilities.

Automation must respect the target website's terms and applicable law.
