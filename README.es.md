## 🔍 Herramientas de Detección de Fingerprint

| Herramienta | Propósito |
| ----------- | --------- |
| [BrowserLeaks](https://browserleaks.com/) | Pruebas de Canvas, WebGL, WebRTC, DNS y señales del navegador |
| [CreepJS](https://abrahamjuliot.github.io/creepjs/) | Investigación detallada de fingerprint del navegador |
| [Pixelscan](https://pixelscan.net/) | Comprobación de entorno del navegador y señales de bot |
| [AmIUnique](https://amiunique.org/fingerprint) | Observación de unicidad y fingerprint del navegador |
| [Fingerprint Playground](https://demo.fingerprint.com/playground) | Demostración de identificación de fingerprint |

Consulte la lista completa de [herramientas de detección](docs/es/detection-tools.md).
