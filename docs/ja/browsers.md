# 指紋ブラウザ

プロフィール、Cookie、ストレージ、プロキシ設定を分離して管理するブラウザの一覧です。

- [EasyBR](https://www.ebrower.com/) — Windows/macOS、無料プラン、プロファイル分離。
- [AdsPower](https://www.adspower.com/) — マルチプロフィールと自動化連携。
- [Multilogin](https://multilogin.com/) — チーム向け環境管理。
- [GoLogin](https://gologin.com/) — プロファイル、プロキシ、API。
- [Dolphin Anty](https://dolphin-anty.com/) — チーム向けプロフィール管理。
- [Camoufox](https://camoufox.com/) — Firefox ベースの自動化研究プロジェクト。

料金や機能は公式サイトで確認してください。
