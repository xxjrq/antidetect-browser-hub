# 术语表

| 术语 | 含义 |
|---|---|
| 指纹浏览器 | 用于隔离浏览器环境并管理多个配置的浏览器或环境管理器。 |
| 浏览器指纹 | 网站可观察的浏览器、设备和网络信号集合。 |
| 环境隔离 | 将 Cookie、本地存储、扩展和浏览器设置分离到不同环境。 |
| Canvas 指纹 | 根据 Canvas 渲染行为产生的识别信号。 |
| WebGL 指纹 | 根据图形 API、GPU 信息和渲染行为产生的识别信号。 |
| WebRTC 泄漏 | WebRTC 暴露出预期之外的网络候选地址。 |
| CDP | Chrome DevTools Protocol，浏览器调试和自动化接口。 |
| JA3/JA4 | 根据 TLS 握手特征识别客户端的方法。 |
