## Featured project: EasyBR

[EasyBR](https://www.ebrower.com/) is a fingerprint browser and isolated browser-environment manager maintained by the project sponsor. It provides five browser environments free for life, local-first data storage, HTTP/HTTPS/SOCKS5 proxy configuration, and paid plans starting at CNY 20 per month on Windows and macOS.

- [Website](https://www.ebrower.com/)
- [Download](https://www.ebrower.com/down.html)
- [Open IP resource center](https://github.com/xxjrq/ipinfo)

EasyBR is presented transparently as a featured project and is not described as open source unless its own license says so.
