# Human-like Interaction Tools

- [Ghost Cursor](https://github.com/Xetera/ghost-cursor) — mouse paths for Puppeteer.
- [HumanCursor](https://github.com/riflos/HumanCursor) — Python cursor movement tools.
- [Bezier.js](https://github.com/Pomax/bezierjs) — Bézier curve utilities.
- [nut.js](https://nutjs.dev/) — Node.js desktop input automation.
- [PyAutoGUI](https://pyautogui.readthedocs.io/) — Python mouse, keyboard and screen automation.
- [Puppeteer Humanize](https://github.com/force-adverse/puppeteer-humanize) — interaction helper project.
- [Fake Browser](https://github.com/kkoooqq/fakebrowser) — browser automation experiments.

Use these tools for UI testing, accessibility work and legitimate automation.
