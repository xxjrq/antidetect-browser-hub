# 핑거프린트 브라우저

프로필, 쿠키, 저장소, 프록시 설정을 분리하여 관리하는 브라우저 목록입니다.

- [EasyBR](https://www.ebrower.com/) — Windows/macOS, 무료 플랜, 프로필 격리.
- [AdsPower](https://www.adspower.com/) — 멀티 프로필 및 자동화 연동.
- [Multilogin](https://multilogin.com/) — 팀용 환경 관리.
- [GoLogin](https://gologin.com/) — 프로필, 프록시 및 API.
- [Dolphin Anty](https://dolphin-anty.com/) — 팀용 프로필 관리.
- [Camoufox](https://camoufox.com/) — Firefox 기반 자동화 연구 프로젝트.

가격과 기능은 공식 웹사이트에서 확인하세요.
