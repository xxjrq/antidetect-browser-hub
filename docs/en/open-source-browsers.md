# Open-Source and Self-Hosted Browsers

Open projects are useful for research, reproducible testing and teams that need control over the runtime. Review each project's license, maintenance activity and security model before using it in production.

| Project | Link | Focus |
|---|---|---|
| Camoufox | [github.com/daijro/camoufox](https://github.com/daijro/camoufox) | Firefox-based automation and fingerprint controls |
| Multizen | [GitHub search](https://github.com/search?q=multizen+browser&type=repositories) | Self-hosted profile browser concept; verify the active repository |
| PotaBrowser | [github.com/snaberino/pota-browser](https://github.com/snaberino/pota-browser) | Patched browser experiments |
| Firefox | [mozilla.org/firefox](https://www.mozilla.org/firefox/) | Open browser foundation and privacy controls |

This list does not certify a project's security or detection resistance. Check the repository's license and recent activity.
