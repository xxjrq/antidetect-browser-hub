# 工具数据库

[`data/tools.json`](../../data/tools.json) 收录浏览器指纹检测、自动化、网络指纹、代理/IP 信誉、桌面自动化和隐私测试工具。

## 分类

- **指纹与机器人检测**：用于观察 Canvas、WebGL、WebRTC、自动化信号等公开指标。
- **自动化与测试**：Playwright、Puppeteer、Selenium、CDP 等开发工具。
- **网络与连接**：TLS、DNS、代理和 IP 信誉测试。
- **交互与桌面自动化**：用于合法 QA、回归测试和可访问性场景。

工具只是检测或开发入口，不代表能够绕过第三方平台的安全策略。测试前应确认权限，并遵守目标站点条款。
