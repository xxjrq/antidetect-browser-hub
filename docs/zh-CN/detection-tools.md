# 指纹与机器人检测工具

这些工具用于观察浏览器、网络和自动化环境暴露的信号，检测结果是诊断参考，不是绝对的通过或失败结论。

## 浏览器指纹

- [CreepJS](https://abrahamjuliot.github.io/creepjs/) — 详细的浏览器指纹信息。
- [BrowserLeaks](https://browserleaks.com/) — Canvas、WebGL、WebRTC、DNS 等测试。
- [Pixelscan](https://pixelscan.net/) — 浏览器和机器人检测。
- [Fingerprint Playground](https://demo.fingerprint.com/playground) — 浏览器识别演示。
- [AmIUnique](https://amiunique.org/fingerprint) — 查看浏览器指纹。
- [EFF Cover Your Tracks](https://coveryourtracks.eff.org/) — 隐私和跟踪测试。
- [Sannysoft](https://bot.sannysoft.com/) — 自动化信号测试。
- [BrowserScan](https://www.browserscan.net/) — 浏览器环境检查。
- [WebBrowserTools](https://webbrowsertools.com/) — 多项浏览器信息测试。
- [F.vision](https://fv.pro/check-privacy/general) — 隐私检查，使用前确认当前可用性。

## 自动化与行为检测

- [Rebrowser Bot Detector](https://bot-detector.rebrowser.net/) — 自动化任务与环境检测。
- [Brotector](https://kaliiiiiiiiii.github.io/brotector/) — 自动化与浏览器信号检测。
- [Behavioral Bot Classification](https://bot.incolumitas.com/) — 行为分类演示。
- [Pixelscan Bot Check](https://pixelscan.net/bot-check) — 机器人信号检查。
- [BotChecker](https://botchecker.net/) — 机器人检测；可能离线，使用前确认。

## Canvas、音频与扩展

- [Audio Fingerprint](https://audiofingerprint.openwpm.com/) — AudioContext 指纹。
- [CanvasBlocker Detection Test](https://kkapsner.github.io/CanvasBlocker/test/detectionTest.html) — Canvas 篡改检测。
- [Extension Detector](https://z0ccc.github.io/extension-detector/) — 扩展暴露检测。

## 网络与连接

- [BrowserLeaks WebRTC](https://browserleaks.com/webrtc)
- [BrowserLeaks DNS](https://browserleaks.com/dns)
- [TLS Peet](https://tls.peet.ws/api/all)
- [ProxyDetect](https://proxydetect.live/)
- [IPQualityScore](https://www.ipqualityscore.com/)
- [DNS Leak Test](https://dnsleaktest.com/)
- [IPRoyal WebRTC Leak Test](https://iproyal.com/webrtc-leak-test/) — WebRTC 泄漏。
- [FingerBank](https://fingerbank.org/) — TCP/设备网络指纹。
- [zardaxt](https://github.com/NikolaiT/zardaxt) — 被动 TCP/IP 指纹研究。

工具状态会变化：官网可正常访问的标记为可用；历史项目或未持续测试的项目应在使用前自行验证。检测结果用于诊断，不构成任何“通过”或“不可检测”的保证。
