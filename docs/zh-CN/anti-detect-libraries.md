# 反检测与浏览器自动化技术库

本页参考相关 Awesome 列表的资源范围，按框架重新分类。项目活跃度和兼容性变化较快，使用前应检查最近提交和许可证。

## Playwright

- [Rebrowser Patches](https://github.com/rebrowser/rebrowser-patches) — 面向 Puppeteer/Playwright 的浏览器补丁和运行方案。
- [playwright-ghost](https://github.com/regseb/playwright-ghost) — Playwright 插件实验项目。
- [Invisible Playwright](https://github.com/feder-cr/invisible_playwright) — 修改版 Firefox 与 Playwright 封装项目。
- [Camoufox](https://github.com/daijro/camoufox) — 基于 Firefox 的自动化和浏览器环境控制。

## Puppeteer

- [puppeteer-extra](https://github.com/berstend/puppeteer-extra) — Puppeteer 插件框架。
- [puppeteer-extra-plugin-stealth](https://github.com/berstend/puppeteer-extra/tree/master/packages/puppeteer-extra-plugin-stealth) — 常见自动化特征处理插件；效果需要自行测试。
- [Rebrowser Patches](https://github.com/rebrowser/rebrowser-patches) — Puppeteer/Playwright 运行补丁。
- [MouseEvent screenX/screenY patcher](https://github.com/ObjectAscended/CDP-bug-MouseEvent-.screenX-.screenY-patcher/) — 鼠标事件坐标一致性补丁。

## Selenium 与 Python

- [Nodriver](https://github.com/ultrafunkamsterdam/nodriver) — Python 浏览器控制项目。
- [Zendriver](https://github.com/stephanlensky/zendriver) — Nodriver 相关分支项目。
- [Undetected ChromeDriver](https://github.com/ultrafunkamsterdam/undetected-chromedriver) — 历史较久的 ChromeDriver 修改项目，使用前确认维护状态。
- [Selenium Driverless](https://github.com/kaliiiiiiiiii/Selenium-Driverless) — 无传统驱动的 Selenium 实验项目。

## HTTP/TLS 客户端

- [curl-impersonate](https://github.com/lwthiker/curl-impersonate) — 模拟浏览器 TLS/HTTP 特征的 curl 分支。
- [curl_cffi](https://github.com/lexiforest/curl_cffi) — Python curl 绑定和客户端特征支持。
- [CycleTLS](https://github.com/Danny-Dasilva/CycleTLS) — Node.js/Go TLS 客户端项目。
- [Got Scraping](https://github.com/apify/got-scraping) — 面向抓取场景的 Node.js HTTP 客户端。

这些项目不保证绕过安全系统。使用时应遵守网站规则和法律。
