# Privacy and Security Tools

- [EFF Cover Your Tracks](https://coveryourtracks.eff.org/) — tracker protection test.
- [BrowserLeaks](https://browserleaks.com/) — browser and network exposure tests.
- [uBlock Origin](https://github.com/gorhill/uBlock) — open-source content blocker.
- [Privacy Badger](https://privacybadger.org/) — tracker blocking by EFF.
- [Firefox](https://www.mozilla.org/firefox/) — privacy-oriented open browser.
- [Tor Browser](https://www.torproject.org/download/) — anonymity-focused browser; understand its threat model.

Privacy tools reduce some exposure but do not guarantee anonymity. Read each project's documentation and threat model.
