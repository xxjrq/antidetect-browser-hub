# 人机交互与输入模拟工具

- [Ghost Cursor](https://github.com/Xetera/ghost-cursor) — 为 Puppeteer 生成鼠标移动路径。
- [HumanCursor](https://github.com/riflos/HumanCursor) — Python 鼠标轨迹工具。
- [Bezier.js](https://github.com/Pomax/bezierjs) — 贝塞尔曲线计算，可用于轨迹生成。
- [nut.js](https://nutjs.dev/) — Node.js 桌面输入和屏幕自动化。
- [PyAutoGUI](https://pyautogui.readthedocs.io/) — Python 鼠标、键盘和屏幕自动化。
- [Puppeteer Humanize](https://github.com/force-adverse/puppeteer-humanize) — Puppeteer 交互辅助项目。
- [Fake Browser](https://github.com/kkoooqq/fakebrowser) — 浏览器自动化和交互实验项目。

人机交互工具适合 UI 测试、桌面自动化和可访问性实验，不应被用于垃圾信息或规避平台安全控制。
