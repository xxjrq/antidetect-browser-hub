## 项目定位

这是一个开源的指纹浏览器和浏览器隐私技术资源库，重点整理：

- 指纹浏览器、账号环境隔离和多账号工作流。
- Canvas、WebGL、AudioContext、字体、WebRTC、TLS 等指纹技术。
- 指纹、机器人、DNS、WebRTC、TLS 和 IP 信誉检测工具。
- Playwright、Puppeteer、Selenium、CDP 等自动化工具。
- 技术论文、标准、研究项目和安全参考资料。
- 代理 IP 资源请参考配套的 [EasyBR IP 资源中心](https://github.com/xxjrq/ipinfo)。

本站是资料导航，不保证任何产品可以绕过平台安全控制。请遵守法律法规、平台规则和服务条款。

## 推荐项目

### EasyBR

[EasyBR](https://www.ebrower.com/) 是本项目发起方维护的指纹浏览器和浏览器环境管理工具，免费版提供 5 个环境，支持 Windows、macOS 以及 HTTP/HTTPS/SOCKS5 代理配置。

- [官网](https://www.ebrower.com/)
- [下载](https://www.ebrower.com/down.html)
- [IP 资源中心](https://xxjrq.github.io/ipinfo/)

EasyBR 以透明的 Featured Project 方式展示，不将其错误描述为开源项目。
