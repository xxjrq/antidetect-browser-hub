# 开源和自托管浏览器

开源项目适合研究、可复现测试和需要自行控制运行环境的团队。使用前应查看许可证、最近提交记录、安全模型和维护情况。

- [Camoufox](https://github.com/daijro/camoufox) — 基于 Firefox 的自动化和指纹研究项目。
- [Multizen](https://github.com/) — 自托管浏览器项目入口，使用前确认实际仓库。
- [PotaBrowser](https://github.com/snaberino/pota-browser) — 修改版浏览器实验项目。
- [Firefox](https://www.mozilla.org/firefox/) — 开放浏览器基础和隐私能力。

本页不对任何项目的安全性或反检测效果作保证。
