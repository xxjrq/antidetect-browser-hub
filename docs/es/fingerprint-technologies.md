# Tecnología de fingerprinting

Esta sección cubre señales Canvas, WebGL, AudioContext, fuentes, WebRTC, zona horaria, idioma, TLS y almacenamiento.

- [CreepJS](https://abrahamjuliot.github.io/creepjs/)
- [BrowserLeaks](https://browserleaks.com/)
- [W3C Fingerprinting Guidance](https://w3c.github.io/fingerprinting-guidance/)

Ninguna señal individual determina por sí sola la identidad de un usuario.
