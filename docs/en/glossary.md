# Glossary

| Term | Meaning |
|---|---|
| Anti-detect browser | A browser or profile manager designed to isolate sessions and control selected environment signals. |
| Browser fingerprint | A collection of browser, device and network signals observable by a website. |
| Profile isolation | Separation of cookies, storage, extensions and browser settings between profiles. |
| Canvas fingerprint | A signal derived from canvas rendering behavior. |
| WebGL fingerprint | A signal derived from graphics APIs, GPU information and rendering. |
| WebRTC leak | Exposure of network candidates that may reveal unexpected addresses. |
| CDP | Chrome DevTools Protocol, a browser debugging and automation interface. |
| JA3/JA4 | TLS client fingerprinting methods based on handshake characteristics. |
