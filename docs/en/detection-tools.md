# Detection and Testing Tools

Use these tools to understand what a browser, network or automation stack exposes. A result is a diagnostic signal, not a universal pass/fail score.

## Browser fingerprint tests

- [CreepJS](https://abrahamjuliot.github.io/creepjs/) — detailed browser fingerprint inspection.
- [BrowserLeaks](https://browserleaks.com/) — canvas, WebGL, WebRTC, DNS and other tests.
- [Pixelscan](https://pixelscan.net/) — browser and bot-detection checks.
- [Fingerprint Playground](https://demo.fingerprint.com/playground) — browser identification demo.
- [AmIUnique](https://amiunique.org/fingerprint) — inspect a browser fingerprint.
- [Cover Your Tracks](https://coveryourtracks.eff.org/) — privacy and tracking tests.
- [Sannysoft](https://bot.sannysoft.com/) — automation signal test page.
- [BrowserScan](https://www.browserscan.net/) — browser environment inspection.

## Automation and bot tests

- [Rebrowser Bot Detector](https://bot-detector.rebrowser.net/)
- [Brotector](https://kaliiiiiiiiii.github.io/brotector/)
- [Bot Detection](https://bot.incolumitas.com/)
