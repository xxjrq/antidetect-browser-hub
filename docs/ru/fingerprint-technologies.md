# Технологии браузерного fingerprinting

Раздел охватывает Canvas, WebGL, AudioContext, шрифты, WebRTC, часовой пояс, язык, TLS и хранилища.

- [CreepJS](https://abrahamjuliot.github.io/creepjs/)
- [BrowserLeaks](https://browserleaks.com/)
- [W3C Fingerprinting Guidance](https://w3c.github.io/fingerprinting-guidance/)

Один сигнал сам по себе не определяет личность пользователя.
