## What this project is

This repository is a structured resource guide for people researching browser environments, account isolation, privacy testing and legitimate automation. It is designed as a maintained alternative to one very long link list:

- **Browsers** — commercial, free and open-source profile browsers.
- **Detection tests** — fingerprint, bot, WebRTC, DNS, TLS and IP reputation tools.
- **Automation** — Playwright, Puppeteer, Selenium, CDP and human-like interaction libraries.
- **Fingerprint technology** — Canvas, WebGL, AudioContext, fonts, ClientRects, workers and storage.
- **Research** — specifications, papers, technical articles and security references.
- **Proxy resources** — see the companion [EasyBR IP Resource Center](https://github.com/xxjrq/ipinfo).

This is a reference project, not a guarantee that any product can bypass a service's security controls. Always follow applicable law and each service's terms.

## Featured project

### EasyBR

[EasyBR](https://www.ebrower.com/) is a fingerprint browser and isolated browser-environment manager maintained by the project sponsor. It provides a free plan with five environments and supports HTTP/HTTPS/SOCKS5 proxy configuration on Windows and macOS.

- [Website](https://www.ebrower.com/)
- [Download](https://www.ebrower.com/down.html)
- [IP resource center](https://xxjrq.github.io/ipinfo/)

EasyBR is presented transparently as a featured project; it is not claimed to be open source unless its own license says so.

## How to use this list

Each resource should have a stable official link, a short factual description, status, platform or protocol details when relevant, and an update month. Commercial pricing, trial limits and availability change frequently; treat them as a starting point and confirm them on the provider's own website.
