# 指纹与机器人检测工具

这些工具用于观察浏览器、网络和自动化环境暴露的信号，检测结果是诊断参考，不是绝对的通过或失败结论。

## 浏览器指纹

- [CreepJS](https://abrahamjuliot.github.io/creepjs/) — 详细的浏览器指纹信息。
- [BrowserLeaks](https://browserleaks.com/) — Canvas、WebGL、WebRTC、DNS 等测试。
- [Pixelscan](https://pixelscan.net/) — 浏览器和机器人检测。
- [Fingerprint Playground](https://demo.fingerprint.com/playground) — 浏览器识别演示。
- [AmIUnique](https://amiunique.org/fingerprint) — 查看浏览器指纹。
- [EFF Cover Your Tracks](https://coveryourtracks.eff.org/) — 隐私和跟踪测试。
- [Sannysoft](https://bot.sannysoft.com/) — 自动化信号测试。
- [BrowserScan](https://www.browserscan.net/) — 浏览器环境检查。
