# 自动化工具与库

- [Playwright](https://playwright.dev/) — 跨浏览器端到端自动化。
- [Puppeteer](https://pptr.dev/) — Chrome/Chromium 自动化。
- [Selenium](https://www.selenium.dev/) — 成熟的 WebDriver 生态。
- [WebdriverIO](https://webdriver.io/) — JavaScript 自动化框架。
- [Cypress](https://www.cypress.io/) — Web 应用测试。
- [Chrome DevTools Protocol](https://chromedevtools.github.io/devtools-protocol/) — 底层浏览器控制。
- [Nodriver](https://github.com/ultrafunkamsterdam/nodriver) — Python 浏览器控制。
- [Selenium Driverless](https://github.com/kaliiiiiiiiii/Selenium-Driverless) — 无传统驱动的 Selenium 实验项目。
- [Ghost Cursor](https://github.com/Xetera/ghost-cursor) — 鼠标路径生成。
- [nut.js](https://nutjs.dev/) — 桌面输入自动化。

自动化必须遵守目标网站的服务条款和适用法律。
