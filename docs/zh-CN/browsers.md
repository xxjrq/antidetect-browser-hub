# 指纹浏览器目录

指纹浏览器通过分离 Cookie、本地存储、扩展、代理和浏览器环境，帮助用户管理多个独立配置。常见合法用途包括跨境业务、软件测试、本地化 QA、团队账号管理和隐私研究。

## 选型重点

- Cookie、本地存储、扩展和代理是否按环境隔离。
- Windows、macOS、Linux 和移动端支持情况。
- 是否提供 Playwright、Puppeteer、Selenium 或 API 自动化。
- 环境能否导出、迁移和团队共享。
- 数据存储位置、权限控制和安全政策是否清晰。
- 产品是否持续更新 Chromium/Firefox 内核。

价格、免费额度和产品能力会调整，请以各产品官网当前页面为准。本项目不进行“绝对防封”或“无法检测”等承诺。
